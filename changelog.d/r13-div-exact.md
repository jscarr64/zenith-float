- `ExactNum::div_exact(&self, d2: &Self, p: usize) -> Result<Option<ExactNum>, Error>` (new, R13 for zenith-bound S1): the quotient when it is exact at `p` bits (word-rounded) inside the exponent range, subnormal grid included, else `None` (it would round, overflow, or underflow). `Inf / finite` is `Some(±Inf)`, `finite / Inf` is `Some(±0)`; `x / 0` is `DivisionByZero`, `0 / 0`, `Inf / Inf` and NaN operands are `InvalidArgument` (or the NaN's own kind). Built on the per-operation `inexact()` flag of `div`; no new division code. Additive.
