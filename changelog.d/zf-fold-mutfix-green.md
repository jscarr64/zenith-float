- zenith-float-num (complex gamma family): the integer-shift loops in `ExactComplex::gamma` / `ln_gamma` / `digamma` (before the Stirling / asymptotic series) are now bounded. They go through the new `shift_while_small`, which takes at most `shift_cap(k) = 2^(k-1) + 2` shifts for the shift target k (2^(k-1) shifts are enough because each adds 1 to Re z, which starts at Re z >= 0) and then returns `PrecisionRetryExhausted` (NaN result). Before, arithmetic that did not move z up looped forever: under the PR #39 edgegate mutant `round_exact -> Default::default()` every result was 0, so `complex_special::tests::test_complex_gamma_golds` never finished and the num slice timed out. Correct inputs are unchanged; tests `shift_cap_is_two_to_the_k_minus_one_plus_two` and `shift_while_small_is_bounded` check the cap values, the exact 2^(k-1) steps from a tiny Re z, no steps for a large z, the cap stop and error pass-through.
