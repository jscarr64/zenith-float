- `ExactNum::to_i64`, `to_u64`, `to_i32`, `to_u32` (each `(&self, rm: RoundingMode) -> Result<_, Error>`) and `fits_i64`, `fits_u64`, `fits_i32`, `fits_u32` (each `(&self, rm: RoundingMode) -> bool`) (new, MP18, MPFR `get_sj/uj/si/ui`): `self` rounded to an integer with `rm`, converted or range-checked. Unlike MPFR, which saturates, an out-of-range result is refused with `InvalidArgument` — never a saturated value. `RoundingMode::None` does not round: a non-integer input is refused, an integer input converts. `-0` converts to `0`. NaN input is refused (a carried error propagates, a bare NaN is `InvalidArgument`); Inf input is refused (fits false). Rewritten 2026-11-05 per Rusty's REWRITE ruling: the rounding rebuilds the integer and fractional parts from the mantissa words without copying `self`, and the `i128` conversion borrows the working value (no helper-copy site, no exception, no baseline raise). Tested in `zenith-float-num/tests/mp18_int_getters.rs` against exact values, all four type boundaries, signed zeros, infinities, NaN, huge and tiny values, every rounding mode, and the i64::MAX+0.5 tie rows. Additive.
