- zenith-float-bound: `Ball::contains` decides each endpoint of `mid - x` on its own (`within`: undecided for a NaN, else `|d| <= rad`) and combines the two verdicts in one exhaustive match (`both_within`), so an undecided endpoint always gives `Unknown`. Behaviour is unchanged for every input zf can produce; the old `hi.is_nan() || lo.is_nan()` had a surviving `||`→`&&` mutant (a one-sided failure cannot be produced on demand), and every pair of verdicts is now unit-tested.
