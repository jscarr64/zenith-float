- zenith-float-num (tests, red-first for the PR #39 num-slice edgegate findings): `ExactNum::random_normal` is now compiled for the crate's own unit tests too (`cfg(any(test, feature = "random"))`, the same gate as `ExactNumNumber::random_normal` and `Mantissa::random_normal`), and `ext::rand_tests` runs without the `random` feature. With only `#[cfg(feature = "random")]` the function was not built in the default-feature edgegate run, so its mutant could not be caught. New test `random_normal_seeded_is_the_core_draw_nonzero_normal_at_word_precision` checks that from a fixed seed it is the core draw, a non-zero normal number at word-rounded precision with exponent in range, both signs, NaN for a bad precision.
- New test `complex_special::tests::gamma_family_tiny_argument_takes_the_most_shifts`: complex `gamma` / `ln_gamma` / `digamma` at a tiny real argument (the most shifts before Stirling) and on the imaginary axis at p = 64, 256, 1024, against the real kernel and the recurrences. It guards the shift-loop bound added next.
