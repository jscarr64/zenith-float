- `exact!` / `fbig!` / `expr!` / `cexpr!` literals: the proc macro (which runs on the host) emitted host-sized `u64` mantissa words, so on a 32-bit target every literal failed to compile (`tests/mod.rs`: 54x E0308). It now emits 32-bit halves rebuilt by the hidden `macro_util::from_raw_halves` (split by `macro_util::word_halves`); values and precision are unchanged. `RawKind` now derives `Clone` and `Copy`.
